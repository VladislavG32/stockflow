# Актуальная схема StockFlow

Канонический экспорт формирует Acceptance из изолированной PostgreSQL 17 после применения миграций Drizzle. Исходный коммит, журнал и результат сравнения с обновлённой базой сохраняются в артефактах `integration-environment.txt`, `migration-history.txt` и `migration-upgrade.log`.

SQL поступает из `pg_dump --schema-only --no-owner --no-privileges`. При нормализации убираются случайные маркеры сессии pg_dump, комментарии с версиями и различия в окончаниях строк. В экспорт входят определения объектов базы, включая таблицу журнала Drizzle.
