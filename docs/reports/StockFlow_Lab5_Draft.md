## Цепочка доставки

Verify собирает образы и сохраняет архив частями с SHA-256. Publish проверяет архив и публикует эти образы без пересборки. Stage получает release.env той же цепочки и сверяет SHA коммита. На STAGE передаются файлы этого коммита по SSH.

Stage разрешён только из dev. Publish и Stage запускаются вручную; автоматические триггеры отключены. В этой работе они не запускались.

## Сохранение PostgreSQL и возврат версии

Скрипт сверяет имя хоста, проект Compose и существующий том БД. После проверки digest и SHA образа обновляется только app. Миграции не выполняются, контейнер PostgreSQL и его том сохраняются.

После обновления проверяются /api/ready, image ID приложения и прежний контейнер БД. При ошибке возвращается старый образ и проверка повторяется. Неудачный rollback возвращает код 2. Предыдущая версия также доступна для ручного возврата через rollback-app.sh.
