# Аудит исходной версии

Основа: 4d7097d226402ac5fc3e69de1bd054d0b1bf7494, чистая ветка feature/lab3-stockflow.
Рабочая ветка: feature/labs4-8-preparation. Старые отчёты и Compose ЛР3 сохраняются.

В архиве прочитаны оригинальные методички ЛР1, 4–8. Примеры не считаются
требованиями к реализации. Индивидуального сданного ТЗ StockFlow в архиве нет:
достоверный процент покрытия его функций нужно подтвердить по своему ТЗ.

Уже есть node:test + tsx, четыре группы unit-тестов, HTTP/PG интеграционный
сценарий, Drizzle журнал, неизменяемые операции поступления, серверная валидация.
Удаления через API нет: тестировать несуществующий DELETE как CRUD нельзя.
Нет CI, Docker Hub, автоматической доставки, цены поступления и backup.

Данные LAB3-001, LAB3-STAGE-001, LAB3-PROD-001 не затрагиваются.
Любые контейнерные тесты используют отдельный проект и одноразовую БД.
Существующие VM не являются средой локальных тестов этой подготовки.

Контрольные точки коммитов будут помечены локальными тегами prep-lab4,
prep-lab5, prep-lab6, prep-lab7, prep-lab8-manual, prep-lab8-auto.
Это подготовка, а не свидетельства выполнения лабораторных.
